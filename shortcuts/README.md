
## Zed Keyboard Shortcuts

> [!NOTE]
> Note: You can view all Zed keyboard shortcuts on the [official website](https://zed.dev/docs/key-bindings). Or the cheatsheets [here](https://cheatsheets.zip/zed)
> - Ctrl + Alt + B (Toggle Right Dock)
> - Ctrl + Shift + P (Command Pallete)
> - Ctrl + Shift + V (Preview Readme)
> - Ctrl + Shift + F (Find In Project)
> - Ctrl + J (Toggle Bottom Dock/ Terminal)
> - Ctrl + , (Open Zed settings)
> - Ctrl + - (Zoom Out)
> - Ctrl + + (Zoom In)
> - Ctrl + 0 (Reset Zoom To Normal)
